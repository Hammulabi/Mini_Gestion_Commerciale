**Projet : Mini Gestion Commerciale en Java (mode console)**
                  *Contexte du projet*

*L'objectif de ce projet est de développer une application en mode console permettant de gérer une
petite gestion commerciale. Le programme devra permettre de manipuler des fichiers texte pour
stocker les informations et inclure une fonctionnalité d'exportation de factures au format PDF.*
